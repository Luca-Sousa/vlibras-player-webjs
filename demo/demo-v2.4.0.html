📦 Instalação e Uso

NPM/Yarn:

npm install vlibras-player-webjs@2.4.0 yarn add vlibras-player-webjs@2.4.0

React (Novo!):

import { VLibrasProvider, VLibrasPlayer } from 'vlibras-player-webjs/react'; import { useVLibrasTranslation } from 'vlibras-player-webjs/react/hooks'; function App() { const { translate, isTranslating } = useVLibrasTranslation(); return ( <VLibrasProvider> <VLibrasPlayer text="Olá mundo!" /> </VLibrasProvider> ); }

Vanilla JavaScript:

import { VLibrasPlayer } from 'vlibras-player-webjs'; const player = new VLibrasPlayer(); await player.loadAsync(); await player.translateAsync('Texto para traduzir');

Com Plugins:

import { AnalyticsPlugin } from 'vlibras-player-webjs/plugins/examples'; import { VLibrasPlugins } from 'vlibras-player-webjs/plugins'; const analytics = new AnalyticsPlugin(); VLibrasPlugins.register(analytics);
